\section{Описание на проекта}

\textbf{xml2emmet} е уеб приложение за трансформация на XML в Emmet нотация.
Разработено е съвместно с Петър Добрев като PHP 8.2 проект с REST API и SPA frontend.
В рамките на курса приложението е разгърнато в AWS с EC2, RDS MySQL и S3,
а инфраструктурата е описана като код чрез CloudFormation.

Репозиторий: \url{https://github.com/peterdobrev/xml2emmet}, бранч \texttt{feat/aws-ec2-rds-s3}

\section{CloudFormation}

Файлът \texttt{deploy/cloudformation.yml} описва цялата инфраструктура.
При деплой се създават VPC с публична и две частни подмрежи, security groups,
RDS инстанция, S3 bucket, SSM параметри, CloudWatch лог група и EC2 с Elastic IP.

EC2 инстанцията при първо стартиране автоматично инсталира PHP и Apache,
клонира репото, инсталира AWS SDK, чете credentials от SSM и стартира приложението.

\section{S3 интеграция}

Потребителят може да експортира историята си като JSON файл в S3.
Приложението качва файла и връща presigned URL, валиден 1 час:

\begin{lstlisting}[language=php]
$s3->putObject([
    'Bucket' => $this->bucket,
    'Key'    => "exports/user-{$userId}/{$timestamp}.json",
    'Body'   => json_encode($rows),
]);
$url = $s3->createPresignedRequest(..., '+1 hour');
\end{lstlisting}

EC2 достъпва S3 чрез \texttt{LabInstanceProfile} — без hardcoded credentials.

\section{SSM Parameter Store}

Credential-ите не са записани в кода или конфигурационни файлове.
При стартиране bootstrap скриптът ги чете от SSM и ги подава на Apache
като environment variables:

\begin{itemize}
  \item \texttt{/xml2emmet/db/host}, \texttt{db/user}, \texttt{db/pass}
  \item \texttt{/xml2emmet/s3/bucket}, \texttt{s3/region}
\end{itemize}
